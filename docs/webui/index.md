# Web 界面总览

固件 2.0.0.1 的中文 WEBUI 是 **4 个主菜单、17 个页面**。以二层交换管理为主。

顶部显示设备型号、当前用户和注销。语言：简体中文、English、Русский язык、日本語、한국어。

「状态信息」分组里也有可以改转发表的操作，不能把这一组整体当成只读。

## 公共按钮

| 按钮 | 出现位置 | 页面呈现 | 验证边界 |
|---|---|---|---|
| 刷新 | 多数配置页、状态页 | 重新读取页面数据 | 未验证是否丢弃未提交内容 |
| 应用 | IPv4、环路/STP、端口、镜像、聚合、端口 VLAN、风暴控制等 | 推测提交该页配置 | 未执行 |
| 确认 | VLAN、IGMP、静态 MAC 对话框 | 推测提交对话框 | 未执行 |
| 保存 | 多数页面，部分状态页也有 | 可能是全局持久化 | 是否写入启动配置、作用范围、重启后是否保留均未验证 |
| 添加 / 修改 | VLAN、静态 MAC 等 | 打开表单 | 已打开并关闭，没有确认 |
| 删除 / 清除 | VLAN、MAC、统计等 | 可能改变配置、转发表或计数器 | 未执行 |

!!! note "不要从按钮位置反推作用域"
    「保存」出现在状态页，说明它未必只保存当前页。
    「应用后立即生效、保存后永久生效」是常见网管语义，也是厂商视频里的说法，但**不是**这份固件已经用重启验证过的事实。

17 个页面中没有看到独立的 ACL、QoS 队列、802.1X、SNMP、日志服务器、NTP、IPv6 管理、DHCP 服务器、三层路由、PoE、管理 VLAN 选择或巨帧设置入口。
