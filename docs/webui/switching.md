# 高级设置

对应菜单：端口、镜像、链路聚合、端口 VLAN、标签 VLAN、IGMP、风暴控制。

## 端口设置

路径：`/port_settings.html?nav=2-1`

按钮：刷新、应用、保存。

| 配置项 | 页面提供的选项 |
|---|---|
| 端口 | 端口选择控件；表格列出端口 1–10 |
| 状态 | 启用、禁用 |
| 速率 / 双工 | 自动；10Mbps 半双工 / 全双工；100Mbps 半双工 / 全双工；1000Mbps 全双工；2500Mbps 全双工；10Gbps 全双工 |
| 流量控制 | 关、开 |

下方表格分别显示速率/双工和流量控制的「配置」「实际」值。

当时所有端口：启用、速率自动、流量控制**配置**为开启。实际链路是快照，会随接入设备变化：

- 电口可以协商到 100M / 1G / 2.5G
- 光口可以协商到 10G
- 断链端口仍可能显示流控「开启」，这不表示链路上正在交换流控帧
- 某个电口停在 100M，本身不能判为故障

速率下拉框是界面选项全集，不代表每一个物理端口都支持全部速率。本次没有逐端口切换表单验证适用限制。

## 端口镜像

路径：`/port_mirror.html?nav=2-3`

按钮：刷新、应用、保存。

| 配置项 | 可选值 | 当时显示 |
|---|---|---|
| 目的端口 | 丢弃、端口 1–10 | 丢弃 |
| 镜像端口 | 端口选择控件 | 表格覆盖 1–10 |
| 入口 | 禁用、启用 | 所有端口禁用 |
| 出口 | 禁用、启用 | 所有端口禁用 |

一般用途：把指定源端口收到或发出的流量复制到抓包设备所在的目的端口。

!!! warning "「丢弃」不是丢业务流量"
    「丢弃」是目的端口下拉框的原文，表示当前没有选定镜像目的口。
    不能把它解释成交换机正在丢弃正常业务流量。

当时没有启用任何源端口的入口 / 出口镜像。镜像与聚合、STP 的互斥关系未验证。

## 链路聚合

路径：`/link_aggregation.html?nav=2-4`

按钮：刷新、应用、保存。任务型步骤见 [链路聚合指南](../guides/lag.md)。

| 字段 | 页面选项 / 范围 | 当时显示 |
|---|---|---|
| 端口类型（第一列同名字段） | 静态、LAG、LACP | 所有端口均为「静态」 |
| 端口类型（第二列同名字段） | 数值 1–65535 | 所有端口 128，输入框禁用 |
| LACP超时时间 | 短、长 | 所有端口「短」，控件禁用 |
| 聚合组 | 0–15 | 所有端口 0，输入框禁用 |
| LAG状态 | 状态显示 | 随链路变化 |
| LACP系统优先级 | 数值输入框 | 32768 |

这里有明显的中文标签歧义：两个字段都叫「端口类型」。第二个数值字段**可能**是端口优先级，这是推测，不作为确定说明。

「静态」与「LAG」分别代表何种内部模式，页面没有解释。不能仅按通用术语认定所有端口已加入静态聚合。当时聚合组均为禁用的 0，没有足够证据认定已经建立业务聚合组。

界面也未见散列算法、LACP 对端信息或活动 / 被动模式。本次没有切换模式去探查条件字段何时解锁。

## 端口VLAN

路径：`/port_based_vlan.html?nav=2-5`

按钮：刷新、应用、保存。

| 配置项 | 选项 / 作用 | 当时配置 |
|---|---|---|
| 端口 | 选择待配置的物理端口 | 表格覆盖 1–10 |
| PVID | 无标签入站报文的默认 VLAN 归属 | 全部为 1 |
| 接受的帧类型 | 所有、仅标签、仅无标签 | 全部为「所有」 |

虽然菜单名叫「端口VLAN」，实际字段是端口**入口分类**和接收类型，不是另一套独立的端口分组 VLAN。PVID 输入框的可接受边界未通过提交验证。

和标签 VLAN 如何一起用，见 [VLAN 指南](../guides/vlan.md)。

## 标签VLAN

路径：`/tag_based_vlan.html?nav=2-6`

按钮：刷新、添加、删除、保存；每条 VLAN 还有修改、删除入口。

列表列：VLAN ID、VLAN 名称、成员端口、标签端口、无标签端口。

添加 / 修改表单：

| 字段 | 页面形式 / 规则 |
|---|---|
| VLAN ID | 标注范围 2–4094；编辑已有 VLAN 1 时仍显示相同提示，框内为 1 |
| VLAN 名称 | 文本输入；未见长度提示 |
| 端口 1–10 | 每个端口在「无标签端口」「标签端口」「非成员」中三选一 |
| 全选 | 各成员类型列提供全选入口 |
| 提交 / 退出 | 确认、关闭 |

当时只有 VLAN 1，名称为空，成员为端口 1–10，标签端口为空，无标签端口为 1–10。

新建表单中所有端口初始为「非成员」。编辑 VLAN 1 时，所有端口的「非成员」选项均被禁用。

VLAN 1 的限制原因尚不明确：可能是固定保留规则，也可能与端口当前 PVID 为 1 等状态有关。不能假设修改 PVID 后必然解除限制。删除入口的存在也不能证明 VLAN 1 可被删除。

## IGMP侦听

路径：`/igmp_snooping.html?nav=2-7`

主页面按钮：IGMP配置、刷新、保存。主页面明确显示「组播侦听还未开启」。

配置对话框：

| 配置项 | 当时显示 |
|---|---|
| IGMP开关 | 未勾选 |
| 快速离组 | 勾选，但控件禁用 |
| 广播入组报文 | 勾选，但控件禁用 |

一般用途是根据组播成员信息控制组播转发；快速离组影响成员退出后的处理。总开关关闭时，两个灰色勾选项不能作为功能当前生效的证据。「广播入组报文」的精确转发范围尚未验证。

当前可见表单没有按 VLAN 配置、Querier、版本选择或定时器。未启用功能去探索其后的界面。

## 风暴控制

路径：`/storm_control.html?nav=2-8`

按钮：刷新、应用、保存。

| 配置项 | 页面选项 / 范围 |
|---|---|
| 风暴类型 | 广播、多播、未知单播、未知多播 |
| 端口 ID | 端口 1–10 |
| 状态 | 开启、关闭 |
| 速率 | 1–1000 Mbps |

下方表格按端口列出四类流量的速率。当时端口 1–10 的全部数值均为 0。

上方编辑区初始状态显示「开启」，速率为空。不能把编辑区初始选项当成所有端口的真实开关状态。

0 的具体语义未说明：可能表示未启用或未配置，不能解释成「所有此类流量均被限为零」。该页是特定流量类别控制，不是通用的端口总带宽限速。
