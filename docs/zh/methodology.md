# 文档怎么读

这份文档故意写得保守。交换机页面上能勾选的东西，和数据包真正怎么走，中间隔着「提交」和「验证」两步。很多网文会把这两步省略掉。

|---|---|---|
| 2026-09-16 对一台 2.0.0.1 / A0 设备的中文 WEBUI 逐页核对 | 菜单、字段、选项、当时显示、页面路径 | 不代表出厂默认，也不代表转发行为 |

## 四个证据等级

全文表格和步骤使用同一套词：

**已见 UI**  
页面上有这个控件。例如标签 VLAN 的端口有「无标签 / 标签 / 非成员」三选一。

**已读当前值**  
当时屏幕上的数字或选项。例如 PVID 全部为 1。这是快照，可能已被前人改过。

**已提交**  
点击了应用、确认或保存，并看到页面反馈。当前正文几乎没有这一档。

**已验证转发**  
用抓包、对端 VLAN 口或业务流量证实。当前正文没有这一档。VLAN 指南里的 Access/Trunk 对照表是**配置原理示例**，没有在设备上应用。

另外还有 **厂商 / 社区**：来自公开资料。会单独标明。

## 怎样读「当前值」

- 管理 IP、用户名、链路速率、错误包计数都属于**那一台机器当时的状态**。
- 正文一般把它们改写成「当时如何」，需要出厂值时改用厂商/社区来源。
- 温度为瞬时值；断链端口仍可能留下历史计数。

## 怎样读按钮

| 按钮 | 已见 UI | 本仓库的写法 |
|---|---|---|
| 刷新 | 多数配置页、状态页 | 重新读取页面；会不会丢掉未提交内容未验证 |
| 应用 | IPv4、环路/STP、端口、镜像、聚合、端口 VLAN、风暴控制等 | V2.0：应用新设置；本次未点 |
| 确认 | VLAN、IGMP、静态 MAC 对话框 | 推测提交对话框；未执行 |
| 保存 | 多数页面，包括端口统计 | V2.0：保存当前配置；断电后是否仍在未验证 |
| 添加 / 修改 | VLAN、静态 MAC | 已打开表单并关闭 |
| 删除 / 清除 | VLAN、MAC、统计 | 可能改配置、转发表或计数器；未执行 |

不要因为「保存」出现在某一页，就认定它只保存该页。V2.0 在统计页也把 Save 写成保存当前配置。
不要把「未保存的应用能熬过重启」写成已经验证的事实。

## 可见不等于支持，缺失不等于没有

- 速率下拉框有 10G，不代表端口 1 能跑 10G。
- 环路预防勾选了，不代表已经用环路测试过它的动作。
- 没看到 QoS / IPv6 菜单，只说明**这次可见入口没有**。菜单 `nav` 编号有空缺，可能对应其它 SKU 或旧固件页面，见 [菜单与页面路径](reference/menu-map.md)。

## 生产环境

如果你在用网的交换机上验证文档里尚未确认的项：

1. 先备份（系统工具 → 配置 → 下载配置）。导出是否含密码未验证。
2. 写明拓扑，避免只改一半 VLAN 导致管理口失联。
3. 把结果按 [CONTRIBUTING](https://github.com/chius-me/sks3200-8e2x-doc/blob/main/CONTRIBUTING.zh.md) 的格式开 Issue 或 PR。
