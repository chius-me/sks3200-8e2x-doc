# 系统工具

## 配置

路径：`/config_tool.html?nav=4-1`

可见操作：下载用户配置区域；下载配置、选择文件、上传配置。

本次没有下载，也没有选择文件或上传。因此下列事项都未验证：

- 导出格式（文本 / 二进制 / 是否可读）
- 是否包含密码等敏感字段
- 导出的是运行配置还是启动配置
- 导入后是否重启、是否立刻生效

改 VLAN 或聚合之前，至少先尝试下载一份备份，并确认文件能在本机打开。不要把未脱敏的备份提交到本仓库。

更多注意事项见 [备份与升级](../guides/backup-and-upgrade.md)。

## 固件

路径：`/firmware_manage.html?nav=4-2`

可见操作：下载固件区域；下载固件、选择文件、上传固件。

「下载固件」只是设备页面上的按钮名称，**不代表**从厂商拉取最新版本，也不代表在线检查更新。它更像是把设备当前运行的固件镜像倒出来。本次没有下载，内容来源、格式、校验方式均未知。

上传固件的兼容性检查、失败回滚、升级后是否保留配置，同样未验证。

!!! danger "不要混刷"
    社区讨论里出现过把 SKS3200-5E2X 等近亲型号固件刷到 8E2X 上的做法。本仓库不提供这类步骤。只使用与型号、硬件版本匹配、来源可追溯的固件。
