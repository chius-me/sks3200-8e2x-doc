# 高级设置

对应菜单：端口、镜像、链路聚合、端口 VLAN、标签 VLAN、IGMP、风暴控制。

## 端口设置

路径：`/port_settings.html?nav=2-1`

按钮：刷新、应用、保存。

| 配置项 | 页面提供的选项 |
|---|---|
| 端口 | 端口选择控件；表格列出端口 1–10 |
| 状态 | 启用、禁用 |
| 速率 / 双工 | 自动；10Mbps 半双工 / 全双工；100Mbps 半双工 / 全双工；1000Mbps 全双工；2500Mbps 全双工；10Gbps 全双工 |
| 流量控制 | 关、开 |

下方表格分别显示速率/双工和流量控制的「配置」「实际」值。

当时所有端口：启用、速率自动、流量控制**配置**为开启。实际链路是快照，会随接入设备变化：

- 电口可以协商到 100M / 1G / 2.5G
- 光口可以协商到 10G
- 断链端口仍可能显示流控「开启」，这不表示链路上正在交换流控帧
- 某个电口停在 100M，本身不能判为故障

中文下拉框把全部速率放在同一个控件里。厂商手册 V2.0 分开写：

- **电口：** 10 Mbps 半/全、100 Mbps 半/全、1000 Mbps 全、2500 Mbps 全
- **SFP/SFP+：** 1000 Mbps 全、2500 Mbps 全或 10 Gbps 全，取决于型号和模块

本次没有逐口提交表单，去确认界面会不会把不合法的选项灰掉。

## 端口镜像

路径：`/port_mirror.html?nav=2-3`

按钮：刷新、应用、保存。

| 配置项 | 可选值 | 当时显示 |
|---|---|---|
| 目的端口 | 丢弃、端口 1–10 | 丢弃 |
| 镜像端口 | 端口选择控件 | 表格覆盖 1–10 |
| 入口 | 禁用、启用 | 所有端口禁用 |
| 出口 | 禁用、启用 | 所有端口禁用 |

厂商手册 V2.0：交换机只支持 **一组** 镜像。入口 = 源口**收到**的流量；出口 = 源口**发出**的流量。抓包设备接在目的（监视）口。

!!! warning "「丢弃」不是丢业务流量"
    「丢弃」是目的端口下拉框的原文，表示当前没有选定镜像目的口。
    不能把它解释成交换机正在丢弃正常业务流量。

当时没有启用任何源端口的入口 / 出口镜像。镜像与聚合、STP 的互斥关系未验证。

## 链路聚合

路径：`/link_aggregation.html?nav=2-4`

按钮：刷新、应用、保存。任务型步骤见 [链路聚合指南](../guides/lag.md)。

| 字段（中文界面 / V2.0 英文） | 页面选项 / 范围 | 当时显示 |
|---|---|---|
| 端口类型 / Port Type | 静态、LAG、LACP | 所有端口均为「静态」 |
| 端口类型（数值） / Priority | 1–65535 | 所有端口 128，输入框禁用 |
| LACP超时时间 / LACP Timeout | 短、长 | 所有端口「短」，控件禁用 |
| 聚合组 / Aggregation Group | 0–15 | 所有端口 0，输入框禁用 |
| LAG状态 / LAG Status | 状态显示 | 随链路变化 |
| LACP系统优先级 | 数值输入框 | 32768 |

中文界面把模式和那个数值列都标成「端口类型」。厂商手册 V2.0 把第二列叫做 **Priority**（聚合协议用的端口优先级）。

厂商含义（本机没有实际建组）：

- **静态：** 默认无聚合
- **LAG：** 静态链路聚合
- **LACP：** 动态聚合
- **LACP 超时：** 长 = 90 秒，短 = 3 秒
- **聚合组：** 最多 16 组（和 0–15 的控件一致）
- 成员口的速率、双工、VLAN 应一致

组号全是禁用的 0，不能当成已经有业务聚合。未见散列算法、对端信息、主动/被动。本次没有切换模式。

## 端口VLAN

路径：`/port_based_vlan.html?nav=2-5`

按钮：刷新、应用、保存。

| 配置项 | 选项 / 作用 | 当时配置 |
|---|---|---|
| 端口 | 选择待配置的物理端口 | 表格覆盖 1–10 |
| PVID | 无标签入站报文的默认 VLAN 归属 | 全部为 1 |
| 接受的帧类型 | 所有、仅标签、仅无标签 | 全部为「所有」 |

菜单名叫「端口VLAN」，字段是 PVID 和接收帧类型。厂商手册 V2.0：所有 = 收带标签和无标签；仅标签 = 只收带标签；仅无标签 = 只收无标签。PVID 相同的口，在标记规则也匹配时，被写成同一个广播域。PVID 输入边界未提交验证。

和标签 VLAN 如何一起用，见 [VLAN 指南](../guides/vlan.md)。

## 标签VLAN

路径：`/tag_based_vlan.html?nav=2-6`

按钮：刷新、添加、删除、保存；每条 VLAN 还有修改、删除入口。

列表列：VLAN ID、VLAN 名称、成员端口、标签端口、无标签端口。

添加 / 修改表单：

| 字段 | 页面形式 / 规则 |
|---|---|
| VLAN ID | 标注范围 2–4094；编辑已有 VLAN 1 时仍显示相同提示，框内为 1 |
| VLAN 名称 | 文本输入；未见长度提示。V2.0：只是管理标签，不影响转发 |
| 端口 1–10 | 每个端口在「无标签端口」「标签端口」「非成员」中三选一 |
| 全选 | 各成员类型列提供全选入口 |
| 提交 / 退出 | 确认、关闭 |

当时只有 VLAN 1，名称为空，成员为端口 1–10，标签端口为空，无标签端口为 1–10。

新建表单中所有端口初始为「非成员」。编辑 VLAN 1 时，所有端口的「非成员」选项均被禁用。

厂商手册 V2.0：标签端口保留 VLAN 标签（近似 802.1Q trunk）；无标签端口去掉标签（近似 access）。Port VLAN 页上设了 PVID 的口，**通常会显示为该 VLAN 的无标签成员**。这个自动联动本次没有提交验证。

VLAN 1 不能选「非成员」的原因仍不清楚。不能假设改 PVID 后限制就消失。删除入口的存在也不能证明 VLAN 1 可被删除。

## IGMP侦听

路径：`/igmp_snooping.html?nav=2-7`

主页面按钮：IGMP配置、刷新、保存。主页面明确显示「组播侦听还未开启」。

配置对话框：

| 配置项 | 当时显示 |
|---|---|
| IGMP开关 | 未勾选 |
| 快速离组 | 勾选，但控件禁用 |
| 广播入组报文 | 勾选，但控件禁用 |

厂商手册 V2.0：要先打开 IGMP 侦听，再配其它组播选项（和灰色字段对得上）。交换机会根据 IGMP 建立端口到组播 MAC 的映射；已知组播只送给有成员的口；**未知组播仍可能在 VLAN 内泛洪**。快速离组会在 leave 之后立刻把端口从组里拿掉，只适合接收端拓扑允许这么做的场景。广播入组报文 = 广播用来加入组播组的报文。

总开关关闭时，两个灰色勾选项不能当成功能已生效。V2.0 截图里打开后还有组表，本次没打开过。关闭状态下没看到按 VLAN、Querier、版本或定时器。

## 风暴控制

路径：`/storm_control.html?nav=2-8`

按钮：刷新、应用、保存。

| 配置项 | 页面选项 / 范围 |
|---|---|
| 风暴类型 | 广播、多播、未知单播、未知多播 |
| 端口 ID | 端口 1–10 |
| 状态 | 开启、关闭 |
| 速率 | 1–1000 Mbps |

下方表格按端口列出四类流量的速率。当时端口 1–10 的全部数值均为 0。

上方编辑区初始状态显示「开启」，速率为空。不能把编辑区初始选项当成所有端口的真实开关状态。

0 的具体语义未说明：可能表示未启用或未配置，不能解释成「所有此类流量均被限为零」。该页是特定流量类别控制，不是通用的端口总带宽限速。
