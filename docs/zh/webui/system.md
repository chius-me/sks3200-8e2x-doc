# 系统功能

对应菜单：系统信息、IPv4地址、用户、环路与STP、重启与恢复。

## 系统信息

路径：`/setup.html?nav=1-1`

带刷新、保存。厂商手册 V2.0 写可以**查看或编辑**设备描述，页面还会显示 IPv4、**IPv6**、MAC、固件等标识。中文核对表没有记下 IPv6 这一行。

| 字段 | 当时读取 |
|---|---|
| 设备描述 | SKS3200-8E2X |
| MAC 地址 | 页面有此字段；不要把任何一台机器的 MAC 写进公共文档 |
| IPv4 地址 | 该机当时的管理地址（已改过，非出厂） |
| 温度 | 瞬时值；页面无阈值 |
| 固件版本 | 2.0.0.1 |
| 硬件版本 | A0 |

## IPv4地址

路径：`/ipv4_address.html?nav=1-2`

按钮：刷新、应用、保存。

| 配置项 | 可选值 / 输入 | 当时显示 |
|---|---|---|
| DHCP 设置（IPv4） | 禁用、启用 | 禁用 |
| IP地址（IPv4） | IPv4 地址 | 静态私网地址 |
| 子网掩码（IPv4） | IPv4 掩码 | 当时为 `/24` |
| 默认网关（IPv4） | IPv4 地址 | 当时已填写 |

这是交换机自身的管理网络参数。页面没有 DHCP **服务器**配置，也没有 VLAN 间路由，也没有管理 VLAN ID 选择器。

厂商对 SKS32 系列写过：改完 IP 后，无论端口属于哪个 VLAN 都可以用新地址访问管理界面。那是厂商说明，未在本固件上验证。

操作步骤见 [第一次登录](../getting-started.md)。

## 用户

路径：`/user_account.html?nav=1-4`

按钮：应用、保存。

表单字段：新用户名、当前密码、新密码、确认新密码。

可见页面没有：

- 用户列表
- 添加多个账号
- 角色或权限
- 密码长度 / 复杂度说明

不要在文档或 Issue 里填写真实密码。

## 环路与STP

路径：`/loop_stp.html?nav=1-7`

按钮：刷新、应用、保存、禁用全部。分「环路检测」和「STP」两个标签页。

配置任务见 [环路与 STP](../guides/loop-protection.md)。

### 环路检测

| 配置项 | 页面范围 / 单位 | 当时显示 |
|---|---|---|
| 环路预防 | 复选框 | 勾选 |
| 时间间隔 | 0 或 1–100，单位 0.1 秒 | 10，即按标注换算为 1 秒 |
| 恢复时间 | 0 或 1–100，单位秒 | 2 秒 |
| 环路检测状态 | 逐端口 1–10 | 文本读取中状态单元格为空，不能据此判定状态 |

页面没有解释数值 0 的特殊含义，本仓库不把它解释成禁用、立即恢复或无限等待。

### STP

| 项目 | 页面内容 | 当时显示 |
|---|---|---|
| 生成树协议 | STP、RSTP 单选 | RSTP 被选中 |
| STP 边缘端口 | 每端口复选框及表头全选框 | 端口 1–10 均未勾选 |
| 状态 | 每端口状态列 | 端口 1–10 均显示「转发」 |

未见桥优先级、路径开销、Hello / Max Age / Forward Delay。

选中 RSTP 只能证明页面当前选择，不能独立证明运行机制，也不能证明它和环路检测如何联动。两者是否互斥、是否自动切换，尚未验证。「禁用全部」的作用范围也未验证。

## 重启与恢复

路径：`/reboot.html?nav=1-9`

两个按钮：重启、恢复。本次未点击。

厂商手册 V2.0：**Restart** 重启交换机；**Restore** 恢复出厂并**清掉已保存配置**，可能中断业务——先备份。页面上仍没有更多说明。管理 IP 和登录是否回到 `192.168.10.12` / `admin`，可以按「出厂」理解，但这里没试过。RST 孔按多久也没测。
