# 状态信息

这一组不都是只读：「静态MAC」可以添加条目，「动态MAC」和「端口统计」有清除。

## 端口统计

路径：`/port_statistics.html?nav=3-1`

按钮：刷新、清除、保存。

表格列：端口、端口状态、链路状态、发送良好数据包、发送错误数据包、接收良好数据包、接收错误数据包。

它是累计包计数，没有实时 Mbps、字节数或错误类型明细。

读取时：

- 所有端口发送错误包为 0
- 接收错误包在个别端口上非零
- 当时已经断链的端口仍保留历史计数

这些数据没有配套的计数起始时间，不能判断错误发生时间、增长速率或原因。排查时应比较有时间间隔的多次读数。本次没有清零计数器。

「清除」可能清计数；未执行，也不知道是否影响其它页。

## 静态MAC

路径：`/br_static_mac_entries.html?nav=3-2`

按钮：刷新、添加、删除、清除、保存。

当时表为空。列表和新建表单字段：

| 字段 | 页面提示 |
|---|---|
| MAC地址 | `xx:xx:xx:xx:xx:xx` |
| 端口 | 文本输入，未显示格式或范围提示 |
| VLAN ID | 1–4094 |

一般用于固定二层转发目的地址与端口、VLAN 的关系。

静态 MAC **不等同于** IP/MAC 绑定、ARP 防护或端口接入认证。页面没有展示这些功能。

## 动态MAC

路径：`/br_dynamic_mac_entries.html?nav=3-3`

按钮：刷新、下一页、清除、保存。查询条件：MAC地址、VLAN ID，另有搜索。

表格列：序号、MAC地址、端口、VLAN ID、老化计时器。

当时可见条目均属于 VLAN 1。老化计时器出现过 300、281、150 等值；未见单位标注，也没有可编辑的全局老化时间字段。不能把显示值 300 直接写成已确认的全局配置。

其中一条为交换机自身 MAC，端口显示 **0**。这可能对应内部管理 / CPU 端口，页面未解释，不能把它当成面板上的物理端口 0。

不要把完整动态 MAC 表贴进公共 Issue：它等于在暴露当时在线终端。
