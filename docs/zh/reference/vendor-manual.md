## 本仓库怎么用它

厂商原文会标明来源。它**不能**代替你在自己设备上点应用、重启或抓包。

| 主题 | V2.0 补充了什么 | 本仓库仍未实测 |
|---|---|---|
| 出厂登录 | `192.168.10.12`，`admin` / `admin`；电脑用 `192.168.10.2`–`.254` | 核对那台机器已经改过，没有读到出厂值 |
| 应用 / 保存 | Apply = 应用新设置；Save = 保存当前配置（端口统计页也这样写） | 未保存配置能活多久，保存是否等于断电后仍在的启动配置 |
| 恢复 | 恢复出厂；会清掉已保存配置；先备份 | 管理 IP / 用户是否回到出厂；RST 孔按多久 |
| 端口速率 | 电口：所列 10/100/1000/2500 Mbps；光口：1000/2500/10G 全双工，取决于型号和模块 | 没有逐口提交下拉框去试 |
| 镜像 | 只支持一组镜像；入口 = 源口收到的，出口 = 源口发出的 | 和聚合 / STP 的互斥 |
| 聚合 | 静态 = 默认无聚合；LAG = 静态聚合；LACP = 动态；**Priority** 是端口优先级；短超时 **3 秒**，长 **90 秒**；最多 **16** 组；成员口速率、双工、VLAN 应一致 | 散列算法、主动/被动、本机真正建成过一组 |
| VLAN | VLAN 名称只是管理标签；Tagged 近似 802.1Q trunk；Untagged 近似 access；Port VLAN 里设了 PVID 的口**通常**会成为对应 VLAN 的无标签成员 | VLAN 1 限制、反向是否改 PVID、实际转发 |
| IGMP | 先开侦听再配其它组播选项；Fast Leave 在离组后立刻从组里拿掉端口；未知组播仍可能在 VLAN 内泛洪 | 打开后的组表；入组报文具体洪泛到哪些口 |
| 动态 MAC | 老化计时器是剩余寿命，匹配流量会刷新；**默认 300 秒** | 可编辑的全局老化（页面没看到） |
| 固件 | 编程成功后交换机会**自动重启**；不要断电 | 镜像格式、校验、配置是否保留 |

PoE 型号：V2.0 写 PoE 不能单独开关，由设备自动配置。本仓库仍不覆盖 SKS3200-8E2X-P。
