# 硬件概览

SKS3200-8E2X 是兮克 / XikeStor 的轻管理二层交换机：8 个 2.5G 电口加 2 个 10G 光口。
本页把**本次 WEBUI 读到的信息**和**公开规格**分开写。公开规格可能和你手上的批次不完全一致。

## 本次 WEBUI 读到的标识

来源：系统功能 → 系统信息（固件 2.0.0.1，硬件 A0，已见 UI / 已读当前值）。

| 字段 | 读取值 |
|---|---|
| 设备描述 | SKS3200-8E2X |
| 固件版本 | 2.0.0.1 |
| 硬件版本 | A0 |
| IPv4 地址 | 该机当时已改为私网静态地址，不是出厂值 |

温度是瞬时读数，页面没有给出工作温度阈值，不能单凭一个数字判断是否过热。

## 端口

面板从左到右通常是电源、8 个 RJ45、2 个 SFP+，最外侧有 RST 孔。
Web 里端口编号为 **1–10**。结合本次链路状态和公开资料，对应关系如下：

| Web 端口 | 物理口 | 本次观察到的链路（已读当前值） |
|---|---|---|
| 1–8 | 2.5G RJ45 | 当时 1、2 为 1G 全双工，3 为 100M 全双工，8 为 2.5G 全双工；其余电口有的断开 |
| 9–10 | 10G SFP+ | 当时 10 为 10G 全双工，9 断开 |

中文端口设置下拉框把 10M / 100M / 1G / 2.5G / 10G 放在一起。厂商手册 V2.0 分开写：电口为所列 10/100/1000/2500 Mbps；SFP/SFP+ 为 1000/2500/10G 全双工，取决于型号和模块。本次没有逐口提交表单。

## 和 SKS3200-8E2X-P 的区别

带 `-P` 的是 PoE 版本。本仓库只覆盖非 PoE 的 **SKS3200-8E2X**。
2.0.0.1 的可见菜单里也没有 PoE 相关页。
