# 固件分代

同一型号 **SKS3200-8E2X** 在市面上至少出现过两套 Web 配置模型。
混用步骤是这台交换机文档里最常见的坑。

## 本仓库覆盖的版本

| 项 | 值 |
|---|---|
| 型号 | SKS3200-8E2X |
| 硬件 | A0 |
| 固件 | 2.0.0.1 |
| VLAN | 「端口VLAN」+「标签VLAN」 |
| 可见菜单 | 4 组 17 页 |

社区有人提到新到货设备预装 2.0.0.1，VLAN「看起来像正常的 Port / Tagged VLAN」，没有 Bridge 相关配置。这与本次逐页核对一致。

## 更早的一套界面（不在本仓库逐步说明）

2025 年前后的评测、拆机文和部分脚本，描述的是另一套 WEBUI：

| 特征 | 旧界面（社区描述） | 2.0.0.1（本次已见 UI） |
|---|---|---|
| VLAN | 端口绑定 Bridge ID；一个物理口可进多个 Bridge | 端口 VLAN（PVID / 接收帧类型）+ 标签 VLAN（成员 / 标签 / 无标签） |
| 管理连通 | 有文案称需连在 Bridge ID = 0 的口才能打开 Web | IPv4 页无管理 VLAN；厂商 SKS32 说明写「任意 VLAN 都可访问管理 IP」（未在本固件验证） |
| 其它页面 | 评测里出现过 IPv6、系统时间、SNTP | 本次可见菜单没有这些入口 |
| 自动化 | [`ren-e/xikestor`](https://github.com/ren-e/xikestor) 的 `swctl` 按 native VLAN + bridge 条目来写配置 | 没有 Bridge 可填，不能把该脚本直接套过来 |

旧界面的具体字段没有在本次核对中打开，本仓库**不**把那些步骤展开成可执行指南，以免和 2.0.0.1 缠在一起。

## 使用规则

1. 打开 **系统功能 → 系统信息**，先看固件版本和硬件版本。
2. 左侧若是「端口VLAN / 标签VLAN」，按本仓库的 [VLAN 指南](../guides/vlan.md) 走。
3. 左侧若是 Bridge ID / 桥接，你看的是另一套固件。不要按本仓库的两页模型去点，也不要按 `swctl` 去改 2.0.0.1。
4. 贡献新观察时必须带固件号。若你有旧固件的逐页记录，欢迎另开目录或明确标注分代，而不是改写现有 2.0.0.1 段落。

## 近亲型号

| 型号 | 和本文的关系 |
|---|---|
| SKS3200-8E2X-P | PoE 版本；菜单会多供电相关项，本仓库不覆盖 |
| SKS3200-5E2X 等同系列 | 口数不同；社区有过混刷讨论，本仓库不提供混刷步骤 |
| SKS3200M 更早产品线 | 登录页和菜单都可能不同 |

硬件 A0 是本次系统信息里的字样。若你的页面显示其它硬件版本，把差异记到 Issue，不要默认字段完全一样。
